## Admin Tool (`_admin/`)

- [x] Express server (port 3001) — serves repo root + API
- [x] `GET /api/adventures` — lists all adventures, images, and current `links.js` config
- [x] `POST /api/lowres` — generates degraded copy via sharp (1280px wide, JPEG quality 10)
- [x] `POST /api/save` — writes updated `links.js` for an adventure
- [x] `POST /api/publish` — git add + commit + push in one click
- [x] Admin UI — adventure selector, image grid, low-res toggle, URL/credit fields, save + publish buttons
